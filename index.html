Caso de estudio:

Aplicacion Django con SQL

Introduccion: Creacion de una aplicacion que administra clientes, cuentas y transferencias, se implementa Mysql, el cual guarda registros y puede ser consultado

Desafio: Crear y resolver las relaciones junto con la planeacion de los modelos, manteniendo la integridad de los datos y la limpieza de las migraciones creadas en django, junto con la union del backend con los templates.

Propuesta: Se desarrolló un backend sólido utilizando el ORM de Django para modelar 5 tablas interconectadas con 3 tipos distintos de relaciones;uno a uno, uno a muchos y muchos a muchos. Se estructuraron vistas lógicas que validan cada operación y se implementaron consultas SQL eficientes para comprobar y asegurar la correcta funcionalidad del flujo de datos.

Aprendizajes alcanzados:

  • Modelado de bases de datos y creacion de relaciones entre tablas utilizando ORM en Django.
  • Creacion de consultas mediante el ORM de Django.
  • Modularizacion de funciones y escalabilidad
  • Integracion de modelos a templates html y formularios

Metricas de impacto:

  • 5 Tablas relacionales conectadas entre si.
  • 3 Tipos de relaciones: se implementan con exito las relaciones del ORM: uno a uno, uno a muchos y muchos a muchos.
  • 8 Consultas Avanzadas y Operaciones de Agregación: Pruebas superadas con éxito en consola y shell utilizando filtros complejos (exclude), agregaciones (annotate), sumas y promedios, además de consultas con lenguaje SQL.
  • 3 tablas con CRUD Completo: Implementacion de creación, lectura, actualización y eliminación integradas a las vistas y templates.(Cliente, Cuenta y Transacción).
